## How to Use TARX

### Ask Questions

1. Select code in any file
2. Right-click and choose "Ask TARX"
3. Or press `Cmd+K Cmd+E` to explain

### Get Suggestions

Look for comments marked with:
- **TARX TIP:** — Best practices TARX can help with
- **Try:** — Suggested questions to ask TARX

### Example Prompts

```
@tarx explain this function
@tarx what edge cases am I missing?
@tarx refactor this to be more readable
@tarx add error handling
@tarx write tests for this
```

## Keyboard Shortcuts

| Action | Mac | Windows/Linux |
|--------|-----|---------------|
| Open Chat | `Cmd+Shift+T` | `Ctrl+Shift+T` |
| Explain Selection | `Cmd+K Cmd+E` | `Ctrl+K Ctrl+E` |
| Refactor Selection | `Cmd+K Cmd+R` | `Ctrl+K Ctrl+R` |
| Fix Code | `Cmd+K Cmd+F` | `Ctrl+K Ctrl+F` |
| Generate Tests | `Cmd+K Cmd+T` | `Ctrl+K Ctrl+T` |
